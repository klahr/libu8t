## Description
Pre-alpha tokenizer library with UTF-8 support.

## Install
```bash
$ git clone https://git.sr.ht/~klahr/libu8t
$ cd libu8t
$ make
$ sudo make install
```
#### Uninstall
```bash
$ sudo make uninstall
```
